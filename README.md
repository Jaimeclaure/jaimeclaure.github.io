Este repositorio actúa como el Nodo de Almacenamiento, Distribución e Indexación Semántica de activos digitales, papers de investigación científica, documentación técnica y presentaciones interactivas pertenecientes al ecosistema profesional de Jaime Claure.

## 🛠️ Stack Tecnológico e Infraestructura
* **Hosting Global:** GitHub Pages Enterprise Edge Server.
* **Engine Core:** HTML5 / Tailwind CSS (Estructura de diseño geométrico Bauhaus).
* **PDF Engine:** Mozilla PDF.js Core Viewer (Soporte nativo para árboles de capítulos y esquemas de patentes).
* **Slide Engine:** Reveal.js UI Framework (Presentaciones vectoriales aceleradas por hardware).

## 📂 Estructura del Árbol de Directorios
* `/documentos/` : Repositorio de archivos PDF indexados de alta resolución (Papers, CV, Informes).
* `/pdfjs/` : Instancia local de procesamiento y renderizado de documentos con menús de navegación lateral.
* `/slides/` : Módulos de diapositivas interactivas en formato web nativo.

## 🔒 Protocolo de Seguridad y Optimización
* **Filtro Antiscrashing:** Ocultamiento semántico de metadatos en producción.
* **SEO & Performance:** Optimización estática para carga sub-milisegundo en navegadores modernos.
